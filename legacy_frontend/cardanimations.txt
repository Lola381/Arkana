# Advanced UI Interaction Effects Documentation

# 5. Article Hover Reveal with Custom Cursor

## Purpose

This effect creates an interactive article gallery that behaves like a modern editorial or magazine website. Instead of relying on heavy animations, it uses subtle image scaling, animated typography, and a custom cursor to make article browsing feel premium and engaging.

Unlike a page transition, this effect focuses on improving article discovery before navigation occurs.

---

## User Experience

### Initial State

The page displays a collection of article cards.

Each card contains:

* Featured image
* Article title
* Author name

The cards are arranged in a staggered grid layout.

Even-numbered cards are slightly lower than odd-numbered cards to create visual rhythm.

---

### Hover State

When the user moves the mouse over a card:

* A circular "Read" cursor appears.
* The image zooms slightly.
* The article title receives an animated underline.
* Cursor color changes depending on the article.

The result feels similar to premium editorial websites.

---

## Layout Structure

Each article consists of:

ARTICLE

├── Image

└── Full-card Link

├── Title

└── Author

The anchor element covers the entire card.

This makes the whole card clickable.

---

## Custom Cursor System

The browser's default cursor is hidden using:

cursor: none;

A custom circular element is created instead.

The custom cursor contains:

* Circular background
* "Read" label
* Dynamic color system

---

## Mouse Tracking Mechanism

JavaScript listens for:

pointermove

events.

Whenever the mouse moves:

1. Current X coordinate is captured.
2. Current Y coordinate is captured.
3. CSS variables are updated.

The cursor uses these variables to reposition itself.

This creates a perfectly synchronized custom cursor.

---

## CSS Variable Approach

Instead of continuously modifying:

left
top

properties through JavaScript,

the script updates:

--x
--y

variables.

CSS then performs the rendering.

Benefits:

* Better performance
* Less layout recalculation
* Cleaner architecture

---

## Dynamic Color System

The cursor color changes automatically.

Odd-numbered cards use:

* Pink
* Purple tones

Even-numbered cards use:

* Blue tones

Modern CSS :has() selectors detect which card is currently hovered.

This updates:

--hue

which drives cursor color generation.

No JavaScript is required.

---

## Image Zoom Animation

Each image uses:

transform: scale()

Initially:

Scale = 1

During hover:

Scale ≈ 1.2

Result:

Images slowly enlarge.

This creates a cinematic editorial feel.

---

## Animated Underline

The underline beneath article titles is created using:

pseudo-elements.

Initially:

scaleX(0)

The underline is invisible.

During hover:

scaleX(1)

The line grows across the title.

This animation is commonly used on:

* Luxury brands
* Fashion websites
* Design portfolios

---

## Accessibility

Keyboard users are supported through:

:focus-within

Visible outlines appear when navigating via keyboard.

This improves accessibility significantly.

---

## Technologies Used

CSS:

* Grid
* Variables
* Transforms
* Scale
* Translate
* :has()
* Mix-blend-mode
* Pseudo-elements

JavaScript:

* Pointer Events
* CSS Variable Updates

---

## Advantages

✓ Minimal JavaScript

✓ High performance

✓ Modern design

✓ Elegant interactions

✓ Accessible

---

## Limitations

✗ Requires modern browser support

✗ Hover effects have limited usefulness on touch devices

✗ :has() support required

---

* News portals
* Editorial layouts
* Photography galleries
* Blog homepages
* Creative portfolios

# 6. Expanding Profile Card (Poster-to-Profile Reveal)

## Purpose

This component transforms a simple visual card into a detailed information panel.

Initially the card behaves like a poster.

Upon interaction it becomes a profile card containing:

* Description
* Statistics
* Follow controls

The transformation creates an engaging social-media-style experience.

---

## User Experience

### Initial State

The user sees:

* Large image
* Character name
* Frosted glass overlay

Most information remains hidden.

The card prioritizes visual presentation.

---

### Hover State

When hovering:

1. Glass overlay disappears.
2. Image compresses upward.
3. Title changes appearance.
4. Description appears.
5. Footer controls appear.
6. Follow button becomes interactive.

The card transforms from:

Poster → Profile

---

## Layout Structure

CARD

├── Character Image

├── Glass Overlay

└── Content Section

├── Title

├── Description

└── Footer

├── Followers Count

└── Follow Button

---

## Glass Overlay Effect

A pseudo-element creates a blurred panel:

.card::before

This panel uses:

backdrop-filter: blur()

to blur the image beneath.

The result resembles frosted glass.

---

## Purpose of the Glass Layer

The overlay:

* Improves text readability
* Creates depth
* Produces a premium visual effect

---

## Overlay Animation

During hover:

translateY(100%)

moves the glass panel downward.

It slides completely out of view.

The image becomes fully visible.

---

## Image Transformation

Initially:

aspect-ratio: 2/3

The image behaves like a movie poster.

During hover:

aspect-ratio: 1/1

The image becomes square.

This frees vertical space for content.

---

## Object Position Animation

The image focus shifts slightly.

Initial:

object-position: 50% 5%

Hover:

object-position: 50% 10%

This prevents awkward cropping while resizing.

---

## Title Animation

The title begins positioned above its final location.

Initial:

translateY(-200%)

Hover:

translateY(0)

The title slides into place.

The color also changes to match the card theme.

---

## Description Animation

The description starts:

* Invisible
* Positioned below final location

Hover state:

* Opacity increases
* Element moves upward

The result is a smooth fade-and-slide reveal.

---

## Staggered Reveal Sequence

The animation is intentionally staged:

Step 1:

Image changes size

↓

Step 2:

Title settles

↓

Step 3:

Description appears

↓

Step 4:

Footer controls appear

This sequencing feels significantly more polished than revealing everything simultaneously.

---

## Footer Controls

The footer contains:

* Follower count
* Follow button

Initially hidden.

Appears after a short delay.

This delay contributes to the layered animation effect.

---

## Follow Button System

The button contains two pseudo-elements.

These create a:

*

symbol.

---

## Following State

When clicked:

JavaScript toggles:

.following

class.

The vertical line rotates.

The plus sign becomes:

−

The button text changes:

Follow

↓

Unfollow

---

## JavaScript Logic

The script performs three actions:

1. Detect button click
2. Toggle following class
3. Update button text

No complex state management is required.

---

## Dark Theme System

The second card demonstrates theme switching.

Theme changes occur through CSS variables:

--bg

--title-color

--text-color

--button-color

This allows complete visual customization without rewriting component styles.

# Key Difference Between The Two Effects

Article Hover Reveal:

Focuses on content discovery before navigation.

The interaction improves browsing and encourages clicking.

Expanding Profile Card:

Focuses on information disclosure.

The interaction reveals hidden details progressively while keeping the layout compact.

One enhances exploration, the other enhances information presentation.
